# GIS Automation and Hydrological Modeling

## Overview
This project integrates hydrological modeling with hydrographic multibeam data processing to simulate a complete plan-to-product hydrographic workflow.

## Objectives
- Delineate watershed boundaries
- Extract stream networks
- Process multibeam bathymetry
- Generate hydrographic products

## Tools
- ArcGIS Pro
- CARIS HIPS & SIPS
- ModelBuilder

## Workflow
DEM → Fill → Flow Direction → Flow Accumulation → Stream Network → Watershed Delineation

Multibeam Processing:
Import Data → Apply Tide Corrections → Sound Velocity Adjustment → Surface Generation → Export BAG/GeoTIFF

## Outputs
- Watershed boundaries
- Stream network
- Bathymetric surfaces
- BAG and GeoTIFF hydrographic products

## Skills Demonstrated
- Hydrological modeling
- Multibeam bathymetry processing
- GIS automation
